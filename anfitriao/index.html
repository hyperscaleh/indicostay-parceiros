Simulador de viabilidade

Uma ideia de quanto tempo demora a recuperar o investimento

0Receita anual de quartos
0Contribuição operacional
0Recuperação simplificada

Receita = quartos x 365 x tarifa x ocupação. Contribuição = receita x (1 menos custos). Recuperação = investimento / contribuição. Não constitui avaliação financeira, garantia de rentabilidade nem aconselhamento de investimento.

Estudo
brief, terreno, benchmark, CAPEX
Conceito
plantas, renders 3D, materiais
Execução
orçamento, compras, pré-abertura
